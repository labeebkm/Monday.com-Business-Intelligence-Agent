Step D — Deterministic Metrics (lib/bi.ts)
Business Intelligence Layer · No LLM Arithmetic
computePipelineMetrics() — Server-computed, injected into Groq tool result
Groq never computes numbers. All aggregates are calculated deterministically here, then handed to the model as facts. extractFiltersFromQuery() detects sector/quarter/status from natural language.
totalDeals
Count of filtered items
totalRevenue
Sum of value columns (₹ Cr)
averageDealSize
totalRevenue ÷ totalDeals
stageCounts
{ "proposal": 12, "negotiation": 5 }
closedDealsCount
won + lost + completed
nullValues
Data quality caveat trigger
Final answer ready
Response Delivery · text/event-stream
Server-Sent Events (SSE) Stream
Three chunks sent in sequence back to the React frontend. Traces arrive first so the UI can show tool activity before the answer appears.
Chunk 1 — TRACES
Tool call history, endpoints hit, normalization summary, follow-up suggestions
Chunk 2 — ANSWER
Groq's final natural language response with ₹ values, stage breakdown, data caveat
Chunk 3 — [DONE]
Stream termination signal. Frontend stops reading and renders complete UI.
Rendered in browser

Chat UI — Answer + Tool Traces
